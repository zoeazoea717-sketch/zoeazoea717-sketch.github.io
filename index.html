胶片翻拍助手

文件名
胶片翻拍助手_v2.6.zip
版本
v2.6 测试版
适用环境
Windows · Photoshop 2023 (24.2)+

介绍

这是我给用数码相机和片夹翻拍 135 黑白负片做的 Photoshop 插件。选中一卷照片的文件夹，它就能批量调平、裁掉片夹边缘、把负片转正，并设定黑白场。

实拍对照 · v2.2

支持 RAW 和 JPEG，可导出成品 JPEG，也可以保留可继续编辑的分层 PSD。想保留胶片的样子，还可以加胶片边框、生成整卷预览。个别照片识别不准，也能单张修正。

目前还在测试，有些地方可能不够完善。遇到 Bug 或有改进建议，欢迎从首页的平台私信告诉我。

昆特牌狩牌手札

文件名
昆特牌狩牌手札-3.0离线测试版.zip
版本
3.0 离线测试版
核对环境
Windows x64 ·《巫师 3》次世代版 5.01

介绍

这是给《巫师 3》收集昆特牌用的小工具。它能读取你最近的存档，按地区列出还缺哪些牌。可以按名称搜索、按地区或资料片筛选，也能导出缺牌清单。卡表覆盖本体、《石之心》和《血与酒》。

界面实录 · 演示收藏

解压后运行包内的 EXE。退出游戏后，可以单张补牌，或一次补齐所有未拥有的牌种。工具会生成新的手动存档副本，原档保留。再进游戏载入副本。离线补牌无需安装配套 Mod，也用不到控制台。

目前是测试版。存档副本已通过读回校验，尚未在游戏中实际载入验证。建议先试一张，留好原档。任务和成就可能不会随补牌同步。遇到问题或有改进建议，欢迎从首页的平台私信告诉我。

介绍

基于 yt-dlp 开发 ↗

把想保存的视频链接粘贴进来，选好文件夹，就可以交给队列慢慢下。一回要存好几个视频时，也可以一次贴入多个链接。

界面实录 · 1.1.0

可以保留视频的最佳画质，也可以选 MP4。如果只想听声音，就选 MP3，程序会把音轨单独存下来。

下载并运行 Windows 64 位安装包即可。安装包已带上下载和转码所需的组件。
